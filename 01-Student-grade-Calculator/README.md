# Student Grade Calculator

A simple C++ program that calculates a student's total marks, percentage, average, and grade based on marks entered for five subjects.

## 📌 About

This project was created as a beginner C++ project to practice basic programming concepts and understand how different concepts work together in a small application.

The user enters marks for five subjects, and the program processes the values and displays the final result.

## ✨ Features

* Takes marks for five subjects
* Calculates total marks out of 500
* Calculates the percentage
* Calculates the average marks
* Assigns a grade based on the percentage
* Displays a clear result summary

## 📚 Concepts Practiced

This project uses several fundamental C++ concepts:

* Variables
* Data types
* `cin` and `cout`
* Arithmetic operators
* `if`, `else if`, and `else`
* Comparison operators
* Basic calculations
* User input and output

## 🧮 Grading System

| Percentage    | Grade |
| ------------- | ----- |
| 90% and above | A     |
| 80% – 89.99%  | B     |
| 70% – 79.99%  | C     |
| 60% – 69.99%  | D     |
| Below 60%     | F     |

## ▶️ How to Run

Make sure a C++ compiler such as **g++** is installed.

### Compile

```bash
g++ student-grade-calculator.cpp -o student-grade-calculator
```

### Run

On Windows:

```bash
.\student-grade-calculator
```
